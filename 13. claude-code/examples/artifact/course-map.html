Get started

You need Python 3 and Git. These commands download the course and install everything once. On Windows, use python and activate with venv\Scripts\activate.

  1. git clone https://github.com/higgs-labs/ai-llm-course.git
  2. cd ai-llm-course
  3. python3 -m venv venv && source venv/bin/activate
  4. pip install -r requirements.txt

    This can take several minutes: some packages, such as torch, are large.

  5. echo "OPENAI_API_KEY=your-key" > .env

    Most lessons read their keys from .env in the project root. Lessons 1 and 6 don't need one.
